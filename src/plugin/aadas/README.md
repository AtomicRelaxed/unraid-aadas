**AADAS - Auto Array Detection & Swap**

Swap whole disk sets in one Unraid server. At boot, the saved set whose disks are installed exactly is detected and its configuration is applied: slot assignment, pools, shares and *Custom SMB Shares* list. If anything is unclear, nothing is changed and array autostart is held. Release candidate 0.1.0 RC1 - keep a flash backup. [Project page](https://github.com/AtomicRelaxed/unraid-aadas)
